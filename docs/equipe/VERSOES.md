# Versões do projeto

| Versão | O que identifica | Histórico original |
|---|---|---|
| S40 da equipe | Campanha até S40, como estava antes desta integração. O README daquela versão guarda os controles e a descrição das quatro travessias. | [Merge da equipe](https://github.com/miopia-game/miopia/commit/d00f15469d2062c28f5863d92f3c0e1bc68fe63c) · [README da S40](https://github.com/miopia-game/miopia/blob/d00f15469d2062c28f5863d92f3c0e1bc68fe63c/README.md) |
| Revisão jogável do Bosque | Fagulha, interface contextual, fauna redesenhada, animações, testes, vídeos e guia de continuidade. O segundo commit corrige o uso do ambiente Python pelos lançadores. | [Entrega jogável](https://github.com/BersaneV/Miopia/commit/1f7b42c41045ea030d7c4b66739c5570e2d9dd42) · [Lançadores](https://github.com/BersaneV/Miopia/commit/9b70f323fdba82eae2e2c11b3d6398d38d734a38) |
| Estudo opcional do Bosque | Experiência de cenário, leitura do primeiro morcego e esquiva a partir do repouso. A equipe pode experimentar e decidir quais mudanças incorporar. | [Estudo original](https://github.com/BersaneV/Miopia/commit/9dda86557cfb3559c98482eb6638ea322ee861d2) · [Branch de avaliação](https://github.com/BersaneV/miopia-faculdade/tree/estudo/bosque-e-esquiva) |

Os commits da revisão e os da S40 nasceram em dois históricos independentes. A integração reúne os dois com um commit de merge, mantendo as autorias, datas e identificadores. Quem quiser seguir a evolução localmente pode usar `git log --graph --oneline --all`. Para obter as regras atuais do jogo e reproduzir os playtests, consulte o [guia de continuidade](GUIA_DE_CONTINUIDADE.md).
